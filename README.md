# Roxora design assets

Logo files for the Roxora Project.

| File | Use |
| --- | --- |
| `roxora-mark.svg` | The mark on a transparent background. Use this on websites and documents. |
| `roxora-avatar.svg` | The mark on the dark square background, 500×500. |
| `roxora-avatar-500.png` | PNG of the avatar, used for the GitHub org picture. |
| `roxora-avatar-180.png` | PNG of the avatar at 180 px. |
| `roxora-mark-32.png`, `-40.png`, `-80.png` | PNG renders of the mark for places that cannot use SVG. |
| `wallpapers/` | Desktop wallpapers, see [wallpapers/README.md](wallpapers/README.md). |

The mark is a faceted stone in three horizontal bands.

| Part | Colour |
| --- | --- |
| Top band | `#5FD4A8` |
| Middle band | `#2E7A68` |
| Bottom band | `#1F4740` |
| Avatar background | `#12171A` |

The wordmark is "roxora" in lower case, set in Space Grotesk Bold.
